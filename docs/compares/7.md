# Comparison 7 — behavioural parity with upstream `cyclic`, measured pose by pose

The goal changed between [compares/6.md](6.md) and this document. Up to 6 this
repo treated upstream's defects as bugs to fix. From here it is a faithful
transliteration: same behaviour, only the language differs. This is the
measurement of whether that holds, and what it costs.

Three binaries, all on the 18 backbone-cyclised targets of set B, smoke tier,
8 replicas x 200,000 steps, seeds 1-8, same machine:

- **nosso** — `master` at `e31cca8`
- **`cyclic`** — `ccsb-scripps/ADCP` branch tip `1d34035`, built here with
  `gcc -std=c99 -O3 -DNDEBUG -fcommon`
- **ADFRsuite 1.0** — `~/ADFRsuite-1.0/bin/adcp_Linux-x86_64`, built 2019-07-15

## Headline: 144 of 144 poses bit-identical

| gate | resultado |
|---|---|
| set B, ATOM md5 per replica, vs `cyclic` | **144/144 identical** |
| fold fixture, ATOM md5 + final energy | `abf915bc…` / 9.274271, = `cyclic` |
| 3Q47, 16 seeds x 10k, ATOM md5 | 16/16 identical |
| `-h` exit code | rc=1, = `cyclic` = ADFRsuite |
| CA1-CAn median, set B | 2.46 A both arms (crystal 3.83 A) |

This is a stronger gate than anything this repo has used before. Every prior
comparison rested on aggregates -- average fnc, median RMSD -- which can agree
while the trajectories differ. This one requires the same pose, atom for atom,
on every replica of every target.

## What the gate caught that reading the code did not

The first run of it returned **0/144**. A step ladder on 3av9 split the two
binaries at **100 steps**, which rules out floating-point amplification and
means a code difference. Two, in the end:

### 1. `MaxRotamers` defaulted to off

Upstream has no knob here. `scoreSideChain()` and `scoreSideChainNoClash()`
hardcode `if (nbRot > 20)`, so every residue with more than 20 rotamers
(LYS/ARG 81, GLN 36, MET/GLU 27) gets a random subset. Commit `58337c5` made
that configurable and defaulted it **off**, so the default build tried every
rotamer and diverged from upstream on any peptide containing one of those
residues.

It survived five rounds of comparison documents because the only bit-parity
probe in the repo docks `npisdvd`, which contains none of them. `SAKIDNLD`
contains lysine and diverges on the first move.

**This corrects compares/6 and the measurements taken earlier the same day.**
The 4.18x speed gap between this tree and the ADFRsuite binary on set B was
attributed to the collapsed-ring model. It was mostly the rotamer cap:

| arm | set B wall | note |
|---|---|---|
| ours, uncapped, repaired ring | 2339 s | what "4.18x slower" was measured against |
| ours, capped at 20, collapsed ring | **666 s** | current |
| `cyclic` | 578 s | |
| ADFRsuite 1.0 | 559 s | |

Against `cyclic` we are **1.15x** slower, and against the shipped binary
1.19x. That residue is C++ codegen, not behaviour -- the poses are identical.
The ring model contributes far less to throughput than the rotamer cap does.

### 2. `gridenergy()`'s `> 1e9` escape

`7ea27e1` dropped upstream's three `if (outofBoxPen > 1000000000) { fprintf(…);
return erg + 10; }` blocks, on the grounds that they make an atom flung far
outside the box pay LESS than one that barely left. Restored, stderr line and
all.

Not restored: upstream computes the eight stencil indices *before* the
out-of-box return, converting an out-of-range double to int -- undefined
behaviour. Those values are discarded on that path, so keeping the computation
below the return is behaviourally identical, and it stays, like every other
memory/UB fix here.

## What parity costs

### The macrocycle

| source | median CA1-CAn |
|---|---|
| crystallographic ligands | 3.83 A |
| **nosso** | **2.46 A** |
| `cyclic` | 2.46 A |
| ours before the reverts | 3.80 A |

Two alpha carbons at 2.46 A, inside the 3.4 A carbon-carbon van der Waals
contact, on all 18 targets. Intended, and pinned by
`tests/cyclic_closure_test.cpp`.

### Docking quality

Average fnc, same 18 targets:

| rank | nosso | ADFRsuite | ours before | published |
|---|---|---|---|---|
| top1 | **0.200** | 0.253 | 0.353 | 0.444 |
| top5 | **0.380** | 0.476 | 0.474 | 0.569 |
| top10 | **0.432** | 0.521 | 0.493 | 0.652 |
| top100 | **0.596** | 0.627 | 0.624 | 0.857 |

Two things worth separating.

**Against our own previous state**, parity costs 0.15 fnc at top1 and 0.09 at
top5. That is the price of the collapsed ring plus the rotamer cap, and it was
accepted deliberately.

**Against the shipped binary**, we are now *below* it at every rank while being
bit-identical to `cyclic`. That is not a porting defect -- it is evidence about
upstream. The public `cyclic` tip is measurably worse than the binary the
authors ship, which is consistent with the shipped binary sitting a few
internal commits past the public tip (0/16 md5 agreement between them on the
3Q47 probe, measured again here). **Parity with `cyclic` is achievable and
achieved; parity with the shipped binary is not reachable from public source.**

### The A3 hang

Reverting `c6dcf24` restored three swap-pool draws that can fail to terminate,
and the commit reverting it records that they were reproduced on this machine
on 1SFI, 3P8F and 4KEL for nearly two hours on a 200k-step job.

**Not observed in this run**: 0 hung and 0 failed replicas across all 288 runs
in both arms, including those three targets. That matches `cyclic`'s own
behaviour -- the code is byte-identical in both and neither hung here. It does
not mean the hang is gone; it means this budget and these seeds did not reach
the state. The only mitigation remains `ADCP_REPLICA_BUDGET`.

## Conclusion

1. **Parity with `cyclic` is complete and verified at the strongest available
   resolution** -- 144/144 poses, plus the fold fixture and the 16-seed probe.
2. **Two divergences survived five comparison documents** because no probe
   exercised them. Aggregate agreement is not parity; the pose-level gate found
   in one run what reading the diff had missed twice.
3. **The 4.18x claim from earlier today was wrong in attribution.** Most of the
   gap was the rotamer cap, not the ring model. Corrected above.
4. **The shipped binary is better than the branch it came from**, by 0.05 fnc
   at top1 and 0.10 at top5. Chasing it further needs source that does not
   exist publicly.
5. compares/6.md's numbers are superseded: they measured a model this tree no
   longer contains.

## Protocol

```sh
# upstream build
git worktree add <wt> upstream/cyclic
cd <wt> && gcc -std=c99 -O3 -DNDEBUG -fcommon -o adcp_cyclic *.c -lm

# both arms, set B, upstream's own rotamer cap (the default now)
export ADCP_REPLICA_BUDGET=1800
for bin in build/src/adcp <wt>/adcp_cyclic; do
  tests/validation/run_set.sh $bin ~/adcp-bench/targets ~/adcp-bench/results-<arm> smoke B
done

# the gate: ATOM md5 of every run_N.pdb, both arms
# the ladder that localises a divergence, when it fails:
#   run one target at 100 / 1k / 10k / 50k / 200k steps and find where it splits.
#   A split at 100 steps is a code difference; a split only at 200k is FP drift.

tests/validation/ring_geometry.py ~/adcp-bench/results-parP --vs ~/adcp-bench/results-parC
tests/validation/score_all.sh ~/adcp-bench/results-parP
tests/validation/report.py ~/adcp-bench/results-parP --tsv parP.tsv
```
