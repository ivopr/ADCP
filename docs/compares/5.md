# Comparison 5 — pristine `1c1a330` vs HEAD `d409acb` vs upstream `cyclic` vs the ADFRsuite 1.0 binary

First four-way comparison. Two standing arms, unchanged in structure from
[compares/4.md](4.md), plus two new ones:

- **upstream `cyclic`** — `ccsb-scripps/ADCP` branch `cyclic`, tip `1d34035`
  (2019-06-11), 13 commits `upstream/master` never merged, built here with
  pristine's own `gcc -std=c99 -O3 -DNDEBUG -fcommon` line
- **ADFRsuite 1.0** — the binary a normal user actually runs
  (`~/ADFRsuite-1.0/bin/adcp_Linux-x86_64`, built 2019-07-15)

See [5-protocol.md](5-protocol.md) for every command behind every number.

Measured 2026-09-02, same machine as comparisons 2-4: gcc 13.3.0 / clang
18.1.3 / Ubuntu 24.04 / x86-64, Intel i7-12650H (16 threads); all built
binaries `-O3 -DNDEBUG`, the ADFR arm is the vendor's own prebuilt.

## Headline 1: `cyclic` is the shipped binary's lineage — now measured, not inferred

[docs/cyclic-port.md](../cyclic-port.md) argued from DWARF paths and dates
that ADFRsuite ships `cyclic`, not `master`. This comparison confirms it
behaviourally, from a build of the public branch tip:

- both print `PepTide 2.0` and exit 1 on `-h`; pristine and our HEAD print
  the two-line `ADCP 0.1` banner and exit 0
- **the fold fixture is byte-identical between them** — ATOM md5
  `abf915bc58b0eaedf4e4d3a1353f723b`, final energy 9.274271, where pristine
  and HEAD both give `6a438d0a…` / 5.936278

Docking still separates them (16/16 seeds differ), which is exactly what
cyclic-port.md predicted: the shipped binary is a few *internal* commits past
the public tip. The lineage question is settled; the last-mile delta is not.

## Headline 2: HEAD deliberately left pristine's numbers, in one commit, and moved *toward* `cyclic`

For the first time in this series the 16-seed docking table no longer matches
pristine — all 16 seeds moved. A per-commit bisect attributes 100% of the
movement to `7ea27e1` (*adopt upstream cyclic's grid, cysteine and gamma-atom
fixes*); the other four code commits since compares/4 are inert on this
fixture.

Where it landed is the interesting part: **HEAD now agrees with `cyclic`
bit-for-bit on 10 of 16 seeds**, and on 2 more it finds the same energy by a
different pose. Four seeds still differ — the part of the port
cyclic-port.md deliberately stopped short of.

| pair | md5-identical | same energy, different pose | different |
|---|---|---|---|
| HEAD vs `cyclic` | **10/16** | 2/16 | 4/16 |
| pristine vs `cyclic` | 0/16 | 0/16 | 16/16 |
| ADFR vs `cyclic` | 0/16 | 0/16 | 16/16 |

## Headline 3: pristine is alone in crashing

`cyclic` never crashes at any budget and never shows the seed-10 divergence.
Neither does the shipped binary. Pristine's 15/16 segfault redock and its
22,090/22,095 boundary are **`master`-only defects that upstream's own other
branch does not have** — which reframes them: our HEAD didn't fix an ADCP
bug, it independently closed a gap `cyclic` had already closed.

Pristine reproduced every frozen number for the fifth time — fold md5, the
16-seed table value-for-value, the crash map survivor-for-survivor, the exact
seed-10 boundary, the 15/16 segfault redock.

## What moved HEAD off pristine — attributed to one commit

Seed 1 and seed 10, 10,000 steps, one Release build per commit:

| commit | seed 1 | seed 10 |
|---|---|---|
| `e28a5e3` (compares/4 baseline) | -11.0274 | -11.9092 |
| `c6dcf24` bound the swap-pool draws | -11.0274 | -11.9092 |
| **`7ea27e1` upstream cyclic grid/cysteine/gamma-atom** | **-9.21059** | **-11.968** |
| `58337c5` MaxRotamers (opt-in) | -9.21059 | -11.968 |
| `797eb72` Ramachandran index clamp | -9.21059 | -11.968 |
| `7e38b98` sulfur map for methionine | -9.21059 | -11.968 |
| `d409acb` (HEAD) | -9.21059 | -11.968 |

The three fixes after `7ea27e1` are inert here for the reasons they were
written: `MaxRotamers` is off by default, the clamp only fires on an index
already out of range, and the sulfur map only matters for a peptide
containing methionine — `npisdvd` has none.

Cross-checking against the `cyclic` column: `7ea27e1` moved seed 1 to
`-9.21059` and seed 10 to `-11.968`, which are **`cyclic`'s own values**.
The port landed where it aimed.

## Conclusion

1. **`cyclic` is the shipped lineage, confirmed behaviourally** — identical
   banner and a byte-identical fold trajectory with the ADFRsuite binary,
   where `master` matches neither. cyclic-port.md's DWARF argument no longer
   needs to be taken on faith.
2. **HEAD's `7ea27e1` moved it onto `cyclic`'s values**, 10/16 bit-identical
   plus 2 energy-equal. The 4 remaining seeds are the unported remainder,
   now with numbers attached.
3. **Pristine's crashes and its seed-10 UB are `master`-only.** Upstream's
   own other branch has neither. Our fixes closed a gap that `cyclic` had
   already closed by a different route.
4. **Ranking on this target**: HEAD 0.70 Å > ADFR 0.77 Å > `cyclic` 0.88 Å >
   pristine (cannot complete). All three working binaries clear the
   published 2.5 Å threshold with enormous margin.
5. `ctest --test-dir build`: 22/22 pass, working tree unperturbed.
